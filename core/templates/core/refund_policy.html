{% if lang == 'fa' %}لغو و بازپرداخت خدمات{% else %}Cancellation and refunds{% endif %}

{% if lang == 'fa' %}قواعد عمومی پروژه‌های مشاوره، طراحی و توسعه؛ شرایط اختصاصی قرارداد هر پروژه اولویت دارد.{% else %}General rules for consulting, design and development projects; project-specific contracts take precedence.{% endif %}

01

{% if lang == 'fa' %}مهلت لغو اولیه{% else %}Initial cancellation window{% endif %}

{% if lang == 'fa' %}مشتری می‌تواند حداکثر تا دو ساعت پس از ثبت پیش‌پرداخت و پیش از آغاز عملیات اجرایی، درخواست لغو را از مسیر رسمی شرکت ثبت کند. بازپرداخت پس از تطبیق پرداخت و کسر هزینه بانکی احتمالی انجام می‌شود.{% else %}The client may request cancellation through an official channel within two hours of the advance payment and before delivery work begins. Refunds follow payment verification and may exclude unavoidable banking fees.{% endif %}

02

{% if lang == 'fa' %}پس از مهلت لغو{% else %}After the window{% endif %}

{% if lang == 'fa' %}پس از دو ساعت، پیش‌پرداخت به دلیل رزرو ظرفیت، برنامه‌ریزی منابع، تحلیل و زیان ناشی از توقف همکاری قابل بازگشت نیست؛ مگر اینکه قرارداد اختصاصی یا توافق کتبی دیگری وجود داشته باشد.{% else %}After two hours, the advance payment is non-refundable because it covers reserved capacity, resource planning, analysis and cancellation loss, unless a project agreement or written settlement states otherwise.{% endif %}

03

{% if lang == 'fa' %}لغو از طرف شرکت{% else %}Cancellation by the company{% endif %}

{% if lang == 'fa' %}اگر شرکت پیش از ارائه خدمت قادر به انجام تعهد نباشد، مبلغ مربوط به بخش انجام‌نشده بازگردانده می‌شود. میزان کار انجام‌شده و خروجی قابل تحویل مستند خواهد شد.{% else %}If the company cannot perform before delivering the service, payment for the unperformed portion is returned. Completed work and deliverable output will be documented.{% endif %}

04

{% if lang == 'fa' %}روش درخواست{% else %}How to request{% endif %}

{% if lang == 'fa' %}درخواست باید همراه نام سفارش‌دهنده، شماره تماس، شناسه پرداخت و موضوع پروژه از فرم تماس یا شماره رسمی شرکت ارسال شود. نتیجه بررسی از همان مسیر اعلام خواهد شد.{% else %}Submit the client name, phone, payment reference and project subject through the contact form or official phone. The decision is communicated through the verified channel.{% endif %}
